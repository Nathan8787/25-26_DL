# Feature Map Observations（baseline）

以下樣本皆取自測試集，索引對應 pipeline 中輸出的 `feature_maps_sample*` 圖檔；我針對 Layer 0、Layer 3、Layer 5 的變化做定性描述，協助說明 Requirement 1-3。

1. **Sample 3（label 0）**  
   - Layer 0：每個通道幾乎是典型的 Sobel/Gabor 邊緣偵測器，亮區沿著圓形外框與中央豎線。  
   - Layer 3：出現將上下筆畫分開的通道，只留下數字 0 內外輪廓的亮帶。  
   - Layer 5：大多通道只剩外圍一圈亮線，完全忽略背景雜訊，代表網路已萃取出「封閉式輪廓」這個語義。

2. **Sample 2（label 1）**  
   - Layer 0：垂直濾波器特別強，將數字 1 的直線段點亮。  
   - Layer 3：有些通道開始抑制長直線，只保留頂部或底部的小斜線，協助模型分辨 1 與 7。  
   - Layer 5：僅剩中間一條細亮帶，顯示深層只需要「單條脊線」即可決策。

3. **Sample 1（label 2）**  
   - Layer 0：上下橫線與斜腳被不同通道分別強調。  
   - Layer 3：能同時保留左上開口與右下弧線的通道開始出現，顯示模型在組合局部筆畫。  
   - Layer 5：多個通道聚焦在「開口朝左」的 L 型骨架，協助區分 2、3、5。

4. **Sample 18（label 3）**  
   - Layer 0：邊緣濾波器沿著上方與下方的弧線亮起。  
   - Layer 3：部分通道只保留右半邊的兩段弧線，另一部分則凸顯左側的垂直筆。  
   - Layer 5：僅剩中軸線與兩個轉彎亮起，與圖 7 中可視化一致，說明深層特徵專注在「連續的彎曲骨架」。

5. **Sample 4（label 4）**  
   - Layer 0：十字交叉點周圍亮度最高。  
   - Layer 3：能夠同時保留垂直柱與水平橫桿的通道明顯增加，背景則被完全抑制。  
   - Layer 5：許多通道只留下右側垂直柱，另一部分只亮橫桿，暗示模型在組合「柱 + 橫桿」來判斷這個類別。

整體而言，深度越深，特徵圖越像是抽象的骨架或局部筆畫組合，符合我在主報告第 5 節的描述。
